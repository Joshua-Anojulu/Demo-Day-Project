## ✨ Features

| Feature | Description |
|---|---|
| 🎨 **Subject-driven design** | Pitch-dark green background, chalk SVG pitch markings (center circle, halfway line, corner arcs) in the hero |
| 🔤 **Typographic identity** | Anton (display), Archivo (body), Spline Sans Mono (scoreboard labels) |
| 🃏 **Player cards** | Ghosted kit numbers (7 and 10) with animated stat counters that count up on scroll |
| 📡 **Match ticker** | Marquee of quick stats, pauses on hover |
| ⚽ **Rotating ball SVG** | Hand-built wireframe truncated icosahedron that slowly rotates beside the facts section |
| 🧭 **Scroll-spy nav** | Active section highlighted in the navbar as you scroll |
| ♿ **Accessible** | Skip-to-content link, visible keyboard focus rings, semantic HTML5 landmarks |
| 🧘 **Reduced motion** | All animations disabled when `prefers-reduced-motion` is set |
| 📱 **Responsive** | CSS Grid layout adapts cleanly from desktop to mobile |
| 🔌 **Progressive enhancement** | All stats and content render correctly with JavaScript disabled |

## 🛠 Built With

- **HTML5** — semantic, accessible structure (`header`, `main`, `section`, `article`, `footer`)
- **CSS3** — custom properties, Flexbox, Grid, keyframe animations, `clamp()` fluid sizing
- **Vanilla JavaScript** — `IntersectionObserver` for reveals, stat counters, and scroll-spy
- **Google Fonts** — [Anton](https://fonts.google.com/specimen/Anton), [Archivo](https://fonts.google.com/specimen/Archivo), [Spline Sans Mono](https://fonts.google.com/specimen/Spline+Sans+Mono)
